🧪 Option 1: Add Black Screen at the End

This adds a few seconds of black video after each clip.
🔧 Windows Batch Script Example
bat

@echo off
setlocal enabledelayedexpansion

for %%f in (*.mp4) do (
ffmpeg -i "%%f" -f lavfi -i color=black:s=1920x1080:d=3 -filter_complex "[0:v][1:v]concat=n=2:v=1:a=0[outv]" -map "[outv]" "extended_%%f"
)

color=black:s=1920x1080:d=3 creates 3 seconds of black video at 1080p

Adjust s= to match your video resolution

Adjust d= for how many seconds you want to add

🧊 Option 2: Freeze Last Frame

This freezes the last frame for a few seconds.
bat

@echo off
setlocal enabledelayedexpansion

for %%f in (*.mp4) do (
ffmpeg -i "%%f" -vf tpad=stop_mode=clone:stop_duration=3 "extended_%%f"
)

stop_duration=3 adds 3 seconds of frozen last frame

Bend the paperclip into a U-shape

## 🧾 **Fixing Sudden Network Credential Prompts in Windows 11 (Post-GPU Change)**

### 🧠 **Issue**
After swapping the GPU, Windows 11 began prompting for **network credentials** when accessing shared drives—despite previously seamless access and correct sharing/security settings.

### 🔍 **Cause**
Likely triggered by:
- Network profile resetting (e.g., from Private to Public)
- Credential Manager cache invalidation
- SMB protocol or sharing settings being altered
- Windows reapplying stricter defaults after hardware detection

### 🛠️ **Solution: PowerShell Script**
A custom PowerShell script was created to:
- Clear all cached network credentials
- Force network profile to **Private**
- Disable password-protected sharing via registry
- Enable SMB1 and SMB2 protocols
- Flush DNS, reset Winsock and IP stack
- Restart the system to apply changes

### 📜 **Script Summary**
```powershell
# Clear stored credentials
cmdkey /list | ForEach-Object { if ($_ -match "Target:") { cmdkey /delete:($_ -split ":")[1].Trim() } }

# Set network to Private
Get-NetConnectionProfile | Set-NetConnectionProfile -NetworkCategory Private

# Disable password-protected sharing
Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\Lsa" -Name "restrictanonymous" -Value 0
Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\Lsa" -Name "everyoneincludesanonymous" -Value 1

# Enable SMB1 and SMB2
Enable-WindowsOptionalFeature -Online -FeatureName "SMB1Protocol" -NoRestart
Set-SmbServerConfiguration -EnableSMB2Protocol $true -Force

# Reset network stack
ipconfig /flushdns
netsh winsock reset
netsh int ip reset

# Restart
```
